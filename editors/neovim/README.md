# Endo Neovim Integration

Ready-to-use [nvim-dap](https://github.com/mfussenegger/nvim-dap) configuration
for debugging Endo scripts.

## Quick Start

Copy `dap.lua` to `~/.config/nvim/after/plugin/dap-endo.lua`, then open an
`.endo` file and press `<F5>` to start debugging.

## Full Guide

See [docs/debugging/neovim.md](../../docs/debugging/neovim.md) for detailed
setup instructions, breakpoint usage, and troubleshooting.
